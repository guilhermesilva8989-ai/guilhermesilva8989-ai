## 💰 Financeira Rakisan ⭐

Sistema **Full Stack de gestão e simulação de investimentos**, desenvolvido como projeto completo de portfólio e publicado em produção.

### Principais funcionalidades

- Cadastro e autenticação de usuários com JWT
- Dashboard financeiro
- Gerenciamento de carteiras
- Cadastro e acompanhamento de ativos
- Registro de compras e vendas
- Cálculo de patrimônio e rentabilidade
- Metas financeiras com acompanhamento de progresso
- Simulador de investimentos com juros compostos
- API REST
- Banco PostgreSQL em produção
- Interface responsiva
- Deploy completo em nuvem

### Arquitetura

`Next.js` `TypeScript` `NestJS` `Prisma` `PostgreSQL` `JWT` `Docker` `Neon` `Render` `Vercel`
